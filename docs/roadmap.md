# Roadmap de ChessDev

Entrega actual: panel, cuatro líneas introductorias, tres problemas, repaso y Woodpecker, estudios locales PGN, tablero legal de análisis y partidas amistosas autoritativas con cuentas Lichess. Estudios y progreso no se sincronizan entre equipos. No se presenta como un clon funcional completo de ChessFlare.

Pendiente: consentimiento OAuth real y dos cuentas remotas; mayor biblioteca de contenido; motor de análisis si se solicita; repetición espaciada automática y sincronización de estudios. Clasificación, relojes, tienda y pagos requieren alcance separado. No mostrar controles que simulen esas funciones.

Infraestructura gratuita existente: Pages + Worker/D1 + Render. No activar facturación para ampliar alcance.
